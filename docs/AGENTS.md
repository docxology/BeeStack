# docs/ - BeeStack

Keep documentation aligned with the code and manuscript. Prefer concrete module
names, paths, and reproducible commands. Claim strict FlyBody/MuJoCo only for
the Body and small-scene Swarm production outputs that have verifier reports.
Avoid claiming connectome-level neural simulation, full colony-scale BEEHAVE
coupling, calibrated hive thermodynamics, population-of-colonies coupling, or
complete honeybee systems-biology digital-twin status until those backends are
implemented, assimilative, and validated. It is acceptable to document the full
digital-twin target when the text also names the missing datasets, state
variables, validation residuals, and governance boundaries.
