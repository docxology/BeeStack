# Output Figures

Deterministic figures generated by `src/beestack/visualization/figures.py`
through `scripts/analysis_pipeline.py`: module time series, BeeBody
motion-power diagnostics, BeeBrain empirical alignment, BeeMind policy
timeline, BeeSwarm recruitment/pheromone metrics, BeeNiche comb/thermal
metrics, and whole-stack graphical abstracts.

`research/` contains science-first method scorecards, sensitivity figures,
empirical completeness charts, evidence-network views, and per-module research
diagnostics generated by `scripts/run_research_suite.py`.
