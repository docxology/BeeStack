# Empirical Sources

Dryad source catalogs and small downloaded archives generated by
`scripts/fetch_empirical_bee_data.py`.

Large primary files remain opt-in with `--include-large`. Existing large local
archives are preserved in the catalog on later default runs. The current local
resource set includes the Jernigan antennal movement archive; the Paoli calcium
archive is cataloged but currently records a `405 Method Not Allowed` archive
download response.
