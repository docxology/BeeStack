# Output Data

JSON artifacts generated by `scripts/analysis_pipeline.py` and manuscript
variable hydration. `model_card.json` includes stack contracts, the FlyBody
patch plan, validated configuration sections, and BeeBrain empirical dataset
provenance.
`animation_manifest.json` groups artifacts by real FlyBody 3D, reduced
schematic, empirical figure, and diagnostic output, and carries strict
BeeSwarm scene XML/contact-report provenance.
`research_suite_report.json` is the central machine-readable research report;
`sensitivity/sensitivity_sweeps.json` stores deterministic reduced-kernel
sensitivity sweeps used by research figures.
`digital_twin_readiness.json` is generated by
`scripts/assess_digital_twin_readiness.py`; it records conservative maturity
scores and required artifacts for the full systems-biology colony and
population-of-colonies digital-twin target.
`scripts/signpost_project_tree.py` keeps every data subdirectory signposted,
including empirical dataset leaves and nested file-level downloads.

`empirical_sources/` is produced by `scripts/fetch_empirical_bee_data.py`. It
catalogs Dryad files, attempts full curated downloads by default, skips
non-empty local payloads, records archive and file-level download failures, and
downloads Honeybee Standard Brain anatomy assets where upstream access allows.

`empirical_analysis.json`, `empirical_template_bank.json`, and
`bee_brain_end_to_end_report.json` are produced by
`scripts/analyze_empirical_bee_data.py`; they validate downloaded panels,
anatomy inventories, calcium summaries, antennal movement summaries, and the
empirical template bank used by BeeBrain/stack integration.
