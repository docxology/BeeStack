# Generated Reports

Generated Markdown and JSON audits, readiness reports, visual inventories, and publication checks that route figures back to source data and sidecars.

- Scope: Regeneratable reports. Use these as evidence ledgers, not as a replacement for manuscript source, figure metadata sidecars, or raw plot data.
- Regenerate: uv run python scripts/analysis_pipeline.py
- Canonical source: scripts/*.py report writers
